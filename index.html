GitHub Pages & Firebase 設定手順

このアプリケーションをGitHub Pagesで動かすために必要な設定事項です。

⚠️ 必須設定（Googleログインエラー防止）:
Firebaseコンソールで GitHub Pages のドメインを「承認済みドメイン」に追加する必要があります。
  1. Firebase Console を開く
  2. Authentication ＞ 設定 ＞ 承認済みドメイン タブに移動
  3. 「ドメインを追加」をクリックし、あなたの GitHub Pages ドメイン (例: your-username.github.io) を追加
  4. Firestore Database を有効化し、適切なセキュリティルールを設定

推奨 Firestore セキュリティルール:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
